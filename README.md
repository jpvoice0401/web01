## ⚡ v2.5 핵심 기능 상세 설명

### 1. 🔠 0G 키네틱 물리 타이포그래피 엔진 (Kinetic Physics Typography)
메인 포스터와 작가노트에서 작동하는 실시간 캔버스 물리 시뮬레이션 시스템입니다.
* **텍스트 물리 오브젝트화**: `ARTIST JIHYUN` ➔ `PROF.PARK` ➔ `ART DIRECTOR` 키워드가 5초 주기로 유기적 모핑 순환합니다.
* **마우스 반발력 (Repulsion Explosion)**: 마우스/터치가 접근하면 거리에 비례하여 글자 입자들이 사방으로 흩어집니다.
* **자동 귀환 시스템 (Homing & Recovery)**: 분산된 입자들이 **4.5초 뒤** 감쇠 탄성 스프링 물리에 의해 원래 위치(`homeX, homeY`)로 정밀하게 귀환 복구됩니다.
* **50:50 대칭 듀얼 랭귀지 캔버스**: `ARTIST CV`에서 한국어/영문 작가노트가 50:50 황금 대칭을 이루며 실시간 물리 인터랙션을 제공합니다.

---

### 2. 🎵 4-Mode 절차적 앰비언트 오디오 신디사이저 (`sound_engine.js`)
외부 음원 파일 없이 Web Audio API를 활용하여 브라우저에서 실시간 합성하는 고급 사운드스케이프 엔진입니다.
* **🪵 1. MARIMBA**: 펠트 천으로 나직하게 두드리는 따뜻하고 부드러운 우드 톤 (Low-pass Filtered Sine)
* **💧 2. WATER DROP**: 맑은 이슬방울이 수면에 떨어지는 청량하고 둥근 물방울 톤 (Pitch-bend Exponential Sine)
* **🎹 3. FELT PIANO**: 로우파이 피아노 해머의 묵직하고 차분한 어쿠스틱 건반 톤 (Mellow Triangle Envelope)
* **🌬️ 4. AIRY BREEZE**: 고요한 미술관에 부는 산들바람처럼 은은하고 몽환적인 앰비언트 패드 톤
* **우측 하단 원클릭 모드 순환 버튼**: 클릭 시마다 음색이 순차 변경되며 음소거(MUTE) 지원.

---

### 3. 💼 46+ 프로젝트 통합 아카이브 & 스마트 라이트박스
* **4대 카테고리 실시간 필터링**: `ARTWORK`, `MEDIA ART & AX`, `BX & DIGITAL ARCHIVE`, `ACADEMIC`, `ALL` 즉각 필터링.
* **공식 웹 플랫폼 프로젝트 (`jihyunpark-art-official-web`)**:
  * 1080p 고화질 공식 홈페이지 인터랙티브 시연 데모 영상(MP4) 단독 뷰어 탑재.
* **호텔도슨 크리스마스 시네마틱 무드 필름**:
  * 반짝이는 HOTEL DAWSON 조명 연출과 크리스마스 음악이 담긴 오리지널 무드 필름 영상 모달 플레이어 지원.
* **OATH 사운드 아트 전용 오디오 플레이어**:
  * 음원이 포함된 현대미술 작품 클릭 시 `🔊 SOUND ART PLAYING` 플레이어 자동 활성화.

---

### 4. 🌐 3개 국어(한국어 · 영어 · 중국어) 국제 작가 이력서 엔진 (`artist_i18n.js`)
* **무지연 실시간 번역**: `ARTIST CV`에서 `[KOR] [ENG] [CHN]` 버튼 클릭 시 페이지 새로고침 없이 전 섹션(작가노트, 학력, 전시, 소장처, 수상 등)이 즉각 번역 전환.
* **국제 표준 학술·미술 용어 체계**: 글로벌 미술관/갤러리 제출용 국제 표준 영문 및 중문 표기 완비.

---

### 5. 🖨️ 스위스 스타일 에디토리얼 이력서 인쇄 & PDF 내보내기
* **`RESUME (PRINT / PDF)`**: 상단 우측 버튼 클릭 시 브라우저 인쇄 창 즉시 호출.
* **`@media print` 최적화**: 웹 네비게이션 및 인터랙티브 캔버스를 자동 숨김 처리하고, **100% 딥 블랙(#000000)의 정갈한 A4 스위스 에디토리얼 양식**으로 선명하게 PDF 출력 지원.
